# Product Documentation

InnoPhase IoT's Talaria product family is built on a **common platform** that provides shared Wi-Fi, BLE, and security capabilities. Each product variant extends this platform with specific features.

## Product Lines

| Product | Description | Status |
| :--- | :--- | :--- |
| **He** | Ultra-low-power Wi-Fi SoC for IoT sensors | Production |
| **Ne** | Multi-protocol SoC with Wi-Fi + BLE | Sampling |
| **Yo** | High-performance SoC for edge computing | Development |

## Architecture

All products share:

- Common Wi-Fi 7 radio subsystem
- Shared security engine (TrustZone)
- Green Tea Studio™ development environment
- Unified SDK and API surface

Product-specific sections cover unique peripherals, register maps, and application notes.
